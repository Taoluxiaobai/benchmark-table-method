# 商品 = 货 + 匹配流量：找买家就是找商品

## R（原文依据）

> "做生意的第一步是先找到买家。怎么能找到买家呢？买家叫做能够购买商品的人，所以找到买家其实是找到商品。商品不是这有一包纸巾放在这就自然有人来买——商品要有和它相匹配的流量，你要知道什么样的流量能卖得动这个商品，这两个东西加在一起，你才真正拥有这个商品。"

## I（方法论骨架）

三段推理，重构"先有货再找客"的常识：

1. 做生意第一步是找买家
2. 买家 = 能购买商品的人 → 找买家 = 找到"能卖得动的商品"
3. 商品 ≠ 货。商品 = 货 + **与之匹配的流量**。一包纸巾放在那不叫商品，知道"什么内容带来的什么流量能卖掉这包纸巾"，纸巾才变成商品

推论：一个生意成不成立，看的不是货好不好，而是"货-流量"这对组合成不成立。而世上已经有人验证过某对组合成立了——那个人就是你的对标。所以找对标的本质 = 找已被验证的"货+流量"配方。

## A1（作者亲用案例）

这是整条视频的收口原理：作者用它解释了为什么表格第一列只收内容平台上"双透明"的生意——因为在那里，"什么样的内容把什么商品盘活"是公开的，你可以直接看到已被验证的货-流量配对，抄的是整个配方而不是单独抄货。

## A2（什么时候调用我）

- "我手里有货源/有技能，怎么变现？"（→ 反问：你匹配的流量是什么？）
- "为什么他货不如我却卖得比我好？"
- 评估一个"有货无流量"的点子能不能做时

**与相邻 skill 的区分**：本 skill 是第一性原理（为什么对标有效）；落地动作是 `find-benchmarks-on-content-platforms`（去哪找已被验证的配对）和 `benchmark-table-method`（怎么批量筛选）。

## E（执行步骤）

1. 写下你的"货"（实物/服务/技能）
2. 回答：什么样的人会买？他们在哪个内容平台？被什么内容触发购买？答不出 = 你只有货，没有商品
3. 去内容平台搜同类货，找 3 个卖得动的账号，记录它们的"货 + 内容形态 + 流量来源"完整组合
4. 二选一：照抄一个已验证的组合；或保持你的货不变、换一个被验证能卖这种货的流量打法
5. 永远不要反过来：先囤一堆货，再问"这货卖给谁"

## B（边界 / 反例）

- ❌ "我有独家货源所以能成"——货源不是护城河，货-流量配对才是
- ❌ 先进货/先开发产品再找流量——顺序反了，库存会教你做人
- ❌ 成熟生意放量阶段也死磕配对验证——已有稳定渠道时，重点转向放量和复购，不在本 skill 射程内
- ❌ 以为"货 + 任意流量"就成立——流量必须与货匹配，泛流量卖不动垂直货
